# EasyBacklog

使用目标项目的 CLI 管理任务，按用户语言沟通。仅讨论或修改 Skill、普通问答不创建任务。

## 入口与面板

- 先确认目标项目目录和 CLI。已安装工具用 `backlog`；仅在本源码仓库使用 `bun run cli`。不猜测 `easybacklog` 命令，不切到工具源码目录操作其他项目的数据，不自动安装同名包或初始化项目。
- 使用 Skill 时默认启动或复用面板；仅讨论/修改 Skill 或用户要求不打开时跳过。只发送 `$easybacklog` 或要求“打开任务面板”时，直接打开当前项目的 `/board`。仅打开面板时在此结束，无需读取任务指南或操作任务。
- 当前会话已确认属于目标项目且仍响应的服务可复用；已打开则不重复开标签。不能只凭端口响应判断项目。
- 无服务时先确认 `browser --help`，运行 `backlog browser --no-open --non-interactive`（源码仓库用 `bun run cli browser ...`）。按用户指定端口或启动输出取地址，不硬编码，不终止无关进程。保留服务会话，确认就绪后用 `open_in_codex` 打开；无法打开时提供链接并如实说明，不宣称成功。

## 按需读取

首次读 `backlog instructions overview`。同会话、同项目和工具版本下每份指南只读一次，从上下文复用；项目/版本/规则变化或上下文缺失时重读，不每次查版本。只读当前使用的 CLI 或 MCP 一套。

| 动作 | 首次读取 |
| --- | --- |
| 创建/拆分 | `backlog instructions task-creation` |
| 计划/状态/实施 | `backlog instructions task-execution` |
| 验收/关闭 | `backlog instructions task-finalization` |

复杂过滤、父子参数、Shell 引号、字段替换、旧记录边界错误、文档链接及归档恢复删除，才读 `backlog instructions workflow-reference`。MCP 用 `get_backlog_instructions` 的同名 instruction，参考其字段和错误处理；Shell 引号仅适用于 CLI。旧版本缺少参考指南时查相关命令帮助；不熟悉字段用 `--help`，不猜参数。

## 自动任务管理权限

执行任务流程前读取当前项目 `backlog config get automaticTaskManagement`，或当前指南返回的权限。仅 `true` 允许在已授权开发范围内自动创建和更新任务；`false`、未配置或无法确认时，不因普通开发请求自动创建、重开、分配或更新任务。用户明确要求操作任务时仍按请求执行，并保留全部验收要求。只读查询不受限；设置开启不授权额外开发、提交、发布、归档或删除。不得自行将设置改为允许。切换项目、配置变化或权限上下文丢失时重新读取；此规则优先于下文自动跟踪规则。

## 任务流程

- 已知 ID 直接 `backlog task view <ID> --plain`；新需求或未知 ID 用 `backlog search "关键词" --limit 10 --plain`，再读候选；按需扩展，不全量列出。
- 需要规划或交接的开发工作建任务；问答、探索和机械修改不强制建任务。新功能或独立需求须独立记录，先去重，不因同页面/组件就复用旧任务；属于同一父目标才建子任务，不强制把所有后续需求建为子任务。
- 原范围小修复可复用已完成任务，但修改前必须改为项目配置的进行中状态，验证后再关闭；失败或未完成保持进行中。已归档则先恢复，再改状态。
- 小修复：读任务 → 开始 → 修改验证 → 追加结果并关闭。适用的计划可复用，不重复写计划和流水笔记。小修复例外同样适用于子任务；非简单任务仍需研究当前系统并在实施前记录计划，完成必要审批。
- 相容字段可合并：开始状态/负责人；有研究依据且满足前置条件时加入计划。验证后一次更新已证实验收项、DoD、总结和完成状态。不合并互斥字段或依赖前步结果的操作，不延后开始状态。
- 已读任务快照结合本人成功更新可复用；他人可能修改、操作失败/结果不明或上下文缺失时重读。

## 精简记录与验收

记录只保留需求原因、关键决策/阻碍、本次变更、验证证据和遗留事项。通常一段或 3～5 条，复杂证据需要时展开，不设截断上限。验证写明命令或场景和结果，包括失败、跳过、未验证项；长日志用路径引用。

描述不复述验收项，笔记不重复计划，总结不复制笔记；后续只追加新事实。不得为省 token 删除历史、丢弃证据或降低验收、DoD、UI 交互验证及审批要求。只勾选有证据的完成项，通过验证后才关闭。

## 操作边界

任务、草稿、文档、里程碑通过 CLI 修改，不直接编辑 Markdown，ID 由 CLI 分配。保持真实项目的 ID 和状态；追加记录优先，不覆盖历史。查询不自动进入实施，不自行扩大范围或启动未授权工作；管理任务不授权推送、发布或对外发送消息。完成不自动归档/删除。

交付简报实际任务 ID、变更、验证结果和未完成项。
